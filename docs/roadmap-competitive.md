# 競合ギャップ・ロードマップ（2026-07 / v0.3.55時点）

ベンチマーク: Koala Sampler / SP-404MK2 / Teenage Engineering EP-133 / Elektron Digitakt

## P1（v0.3.56で実装）
| 機能 | 競合 | 実装方式 |
|---|---|---|
| WAV書き出し | 全機種 | 編集中パターンを頭から1ループ、マスター出力(finalClip)を実時間キャプチャ→bufToWav |
| リサンプル | SP-404の看板 | 録音ダイアログに「Resample」＝finalClipをpcm直採り経路へ（マイクと同じフロー） |
| リバース | 全機種 | EDITの⇄REVボタン＝破壊的反転（TRIMと同じ流儀・undo可）。start/endは鏡映 |
| メトロノーム | 全機種 | メニューのトグル。拍頭クリック（destination直結＝FX/書き出しに乗らない） |

## P2（次期・要スコープ判断）
- **ソングモード**: パターンの並び（A×4→B×2…）を1行のチェーン表記で。データはproj.song=[{pat,times}]
- **カウントイン**: ●REC＋▶時に1小節クリック先行（メトロノーム基盤の上に）
- **Web MIDI入力**: 外部パッド/鍵盤→trigger()（MC-101等をコントローラに）
- **録音クオンタイズ**: 現在は記録時ステップ吸着のみ→「最近傍ステップ」丸めに
- **ステム書き出し**: グループ別4トラックWAV（P1の書き出し基盤×4パス）
